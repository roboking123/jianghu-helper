# 江湖助手

本工具的目的是最大程度協助玩家的遊玩體驗，不涉及任何遊戲內修改

提供功能如下

## 裝備

- 查看所有打造裝備素質，並查看該裝備洗練、芒晶（含未使用）
- 提供自定義群組卡片功能，你可以自定義想要查看的神裝加入卡片，以卡片為單位篩選達標裝備，並預提供達標裝備有更高cp值做法

## 洗脈

- 查看所有角色原始脈序、無限置換脈序，首紫保底提供夾擠後的有限置換脈序
- 提供自定義群組卡片功能，你可以自定義常用的目標脈序組合，將角色批量分配到不同卡片，並一鍵計算省丹路線及最簡操作步驟，天生支援四換四、首紫保底

## 說明

- 完全離線計算
- 本工具僅為解析計算效益，請自備存檔
- 僅支援國際服
- 支援雙更
- 支援新版存檔，若失效，我會盡快更新
- 省丹路線為我人工提供合法步驟，由腳本在合法步驟範圍內計算，若有步驟未列明則不等同窮舉最佳最省，因此本工具不會自稱最省路線，但若你發現了有手算更省丹的角色，歡迎提供給我
